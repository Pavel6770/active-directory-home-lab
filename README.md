# Лаборатория: Развертывание Active Directory на Windows Server 2022

## 📌 О проекте
Данный проект представляет собой домашнюю лабораторию, развернутую в VirtualBox, для отработки практических навыков системного администрирования.
Цель: построение изолированной сети, развертывание контроллера домена и подключение клиентов.

## 🛠️ Стек технологий
* **Виртуализация:** Oracle VirtualBox
* **Серверная ОС:** Windows Server 2022 (Standard Evaluation)
* **Роли и службы:** Active Directory Domain Services (AD DS), DNS
* **Клиентские ОС:** Windows Server 2022, Windows XP

## 🌐 Схема сети (Internal Network - localnet)
* **Контроллер домена (DC):** IP `192.168.100.1` (DNS настроен на 127.0.0.1, пересылки на 8.8.8.8)
* **Клиент (Server2):** IP `192.168.100.20` (DNS: 192.168.100.1)
* **Клиент (Windows XP):** IP `192.168.100.10` (DNS: 192.168.100.1)

## 🚀 Ключевые достижения
1. Установлен и настроен лес Active Directory (домен `bro.local`).
2. Настроены прямые и обратные зоны DNS, а также DNS-пересылки (Forwarders) для доступа в интернет.
3. Созданы учетные записи пользователей и групп.
4. Успешно осуществлен ввод в домен клиентского сервера (Windows Server 2022).
5. **Решение проблем совместимости:** Проведено исследование проблем аутентификации при попытке ввода в домен устаревшей ОС (Windows XP). Выявлена блокировка старых протоколов (SMB 1.0, Kerberos RC4/DES) на уровне современных обновлений безопасности Windows Server.
